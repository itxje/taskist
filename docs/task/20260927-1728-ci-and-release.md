## Description

Add a GitHub Actions CI workflow that runs the repository's quality gates on every push to
`main` and every pull request, and a tag-driven release workflow that builds static
`tk` binaries for `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl` with the
`dist` profile and publishes them, with checksums, as a GitHub release. The remote is
`git@github.com:itxje/taskist.git`.

Acceptance:

- The CI workflow runs fmt, clippy, nextest, doctests, cargo-deny, cargo-shear, typos and the
  MSRV check, and passes on `main`.
- Pushing a tag `v<version>` that matches `Cargo.toml` builds both musl binaries, checks that
  each is statically linked and runs `tk --version` on its own architecture, and publishes a
  release with one archive per target and a SHA-256 checksum file.
- A tag that does not match the package version fails before building.
- The README documents installing a released binary.
